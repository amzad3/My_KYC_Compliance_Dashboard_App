# Submission checklist

- [ ] Create a **public** GitHub repository named `kyc-compliance-dashboard` (or the name required by the assessment).
- [ ] Upload/push all project files, including `tests/`.
- [ ] Confirm `README.md` explains setup, run instructions, and tests.
- [ ] Run `python -m pytest -q` locally and confirm all tests pass.
- [ ] Run `streamlit run app.py` and verify the dashboard opens.
- [ ] Submit the public repository URL in the assessment portal.

## Suggested Git commands
```bash
git init
git add .
git commit -m "Build KYC compliance dashboard"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/kyc-compliance-dashboard.git
git push -u origin main
```

Replace `<YOUR_USERNAME>` with your GitHub username. Do not submit the placeholder URL.
